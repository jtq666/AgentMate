# AgentMate 对比实验报告

完整逐题结果见 [evaluation/EVALUATION_REPORT.md](evaluation/EVALUATION_REPORT.md)，原始数据见同目录 JSON/CSV。

## 实验设置

- 题集：24 题，覆盖 6 个专题，每个专题 4 题。
- 配置：单 LLM 无 RAG、单 Agent + 混合 RAG、多 Agent 无 Reflexion、完整多 Agent + 混合 RAG + Reflexion。
- 指标：必答点覆盖率、引用有效率/覆盖率、事实错误、平均延迟、模型调用次数、估算 tokens、任务成功率。
- 口径：效果指标由独立模型评测器依据固定参考资料判断；运行成本和效果指标分开统计。

## 核心结果

| 配置 | 必答点覆盖率 | 引用有效率 | 事实错误 | 平均延迟 | 调用次数 | 估算 tokens |
|---|---:|---:|---:|---:|---:|---:|
| 单 LLM、无 RAG | 76.0% | 0.0% | 1 | 6.569 s | 48 | 21,417 |
| 单 Agent + 混合 RAG | 95.8% | 100.0% | 0 | 2.645 s | 48 | 8,714 |
| 多 Agent、无 Reflexion | 92.7% | 100.0% | 0 | 4.340 s | 72 | 14,478 |
| 完整多 Agent + RAG + Reflexion | 95.8% | 100.0% | 0 | 7.879 s | 120 | 35,414 |

四个配置均完成 24/24 题，任务成功率为 100%。

## 结论

1. **混合 RAG 是当前基准的主要质量增益来源。** 相比无 RAG 基线，必答点覆盖率提升 19.8 个百分点，引用有效率从 0% 提升到 100%，事实错误由 1 降至 0。
2. **多 Agent 不天然优于单 Agent。** 多 Agent 无 Reflexion 的覆盖率为 92.7%，低于单 Agent + RAG 的 95.8%。这说明角色拆分会引入上下文传递损耗，必须通过结构化状态和审校控制。
3. **Reflexion 修复了覆盖率，但付出明显成本。** 完整配置从 92.7% 恢复到 95.8%，但相对无 Reflexion 配置调用次数增加 66.7%，估算 tokens 增加约 144.6%，平均延迟增加约 81.5%。
4. **完整多 Agent 的产品价值不应包装成纯准确率提升。** 它的主要收益是证据检索、教学组织、隐藏出题规则、评测和引用审计的职责隔离，以及阶段级重试、可观测和可恢复；对简单问答，单 Agent + RAG 更经济。

## 局限

- 题集规模较小，且固定参考资料使 RAG 配置具有明确证据优势。
- 必答点和事实错误使用模型评测器，仍可能存在评测偏差；后续可增加人工双评和一致性统计。
- tokens 在接口未返回 usage 时按字符数估算，不能直接换算为实际账单金额。
- 当前结论只适用于本次模型、参数和题集，不应外推为所有多 Agent 系统的一般结论。
