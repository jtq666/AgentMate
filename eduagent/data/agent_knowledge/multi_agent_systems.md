# 多Agent系统

## 什么是多Agent系统？

多Agent系统是由多个专业Agent组成的协作系统。每个Agent负责特定任务，通过共享状态或消息通信协作完成复杂任务。

## 设计模式

### 1. 分工协作
每个Agent专精一个领域，通过意图路由分发任务。

### 2. Agent间通信
- **共享状态**：通过统一的 AgentState 交换信息
- **消息传递**：Agent 间发送结构化消息

### 3. 路由策略
用户输入 → 意图分类 → 路由到对应Agent

## 面试要点

1. 为什么需要多Agent而不是一个大Agent？职责分离、可扩展、可独立优化
2. Agent间如何协作？共享状态、消息传递
3. 如何路由用户请求到正确的Agent？LLM意图分类
4. ToolRegistry：统一工具注册，Agent自主发现
