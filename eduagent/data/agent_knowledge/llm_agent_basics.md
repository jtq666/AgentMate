# LLM Agent 基础知识

## Agent 定义

一个 AI Agent 是一个能够感知环境、做出决策、执行行动的自主系统。
在 LLM 时代，Agent = LLM + 工具 + 记忆 + 规划。

## 核心组件

1. **LLM**：大脑，负责推理和生成
2. **工具**：手，调用外部API、数据库、代码执行器
3. **记忆**：存储短期和长期信息
4. **规划**：制定执行计划

## Agent 工作流程

```
用户输入 → 理解意图 → 制定计划 → 调用工具 → 观察结果 → 迭代 → 输出回答
```

## 与传统程序的区别

- 传统程序：固定逻辑，if-else 分支
- Agent：LLM 自主决定调用什么工具、怎么处理

## 面试要点

1. Agent 的定义和核心组件
2. LLM 在 Agent 中的角色
3. Agent 和传统程序的区别
