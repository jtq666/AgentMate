# Agent 记忆系统

## 为什么 Agent 需要记忆？

普通对话 AI 每次从零开始，不知道用户是谁/之前聊过什么。
记忆系统让 Agent 跨会话记住用户信息，实现个性化。

## 三层记忆架构

### 工作记忆（Working Memory）
- 当前对话的滑动窗口
- 保留最近N轮对话
- Token限制防止超出上下文

### 短期记忆（Short-term Memory）
- 对话溢出时压缩保留
- LLM摘要压缩：提取关键信息
- 按话题索引

### 长期记忆（Long-term Memory）
- 跨会话持久化存储
- BM25向量检索召回
- 时间衰减+重要性加权

## 面试要点

1. 为什么分三层？类比人脑的工作记忆→短期→长期
2. 重要性如何评估？LLM自动评分
3. 记忆如何召回？关键词+时间衰减+重要性
4. 跨会话记忆如何实现？JSON持久化+B25检索
