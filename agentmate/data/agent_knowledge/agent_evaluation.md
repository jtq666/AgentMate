# Agent 评估方法

## 如何评估 Agent 系统？

Agent 不同于传统 ML 模型，评估更难，因为：
1. 输出是自由文本，不是分类标签
2. 多步推理的正确性难以自动判断
3. 工具调用的成功与否影响整体结果

## 评估维度

### 任务完成率
Agent 是否成功完成了用户指定的任务？定义成功的标准很关键。

### 工具调用准确率
Agent 是否调用了正确的工具，传了正确的参数？

### 推理质量
Agent 的思考过程是否合理？这通常需要人工评估。

### 效率
Agent 用了多少步完成？是否陷入循环？

## 面试要点

1. Agent 评估的困难：缺少 ground truth
2. 常用的评估方法：人工评估、LLM-as-Judge
3. AgentBench：多个Agent评测基准
4. 工具调用的 accuracy vs latency 权衡
